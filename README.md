# Оноо1600 — SAT бэлтгэлийн сайт

Монгол сурагч, багш нарт зориулсан Digital SAT-ийн **Математик** ба **Англи хэл (Reading & Writing)** бэлтгэлийн вэб апп.

**Сурагчид**
- **Хоёр хэл:** сайт болон тестүүд монгол / англи хэл дээр солигдоно (дээд буланд МОН | ENG).
- **Хугацаатай даалгавар:** цаг дуусахад хариулт автоматаар илгээгдэнэ. Хүндрэлийн түвшинтэй (хялбар / дунд / хүнд).
- **Бодит SAT формат:** 2 модультай adaptive тест. 1-р модулийн дүнгээс хамаарч 2-р модуль хүнд эсвэл хялбар болно.
- **Алдааны дэвтэр:** алдсан асуултууд хуримтлагдаж, дараалан 2 удаа зөв хийвэл гарна.
- **Өдрийн дасгал:** сул сэдвээс автоматаар сонгосон асуултууд.
- **Зорилго ба төлөвлөгөө:** зорилтот оноо, шалгалтын огноогоо оруулбал өдөр бүрийн асуултын тоог санал болгоно.
- **Явцын график, streak, тэмдэг:** оноо цаг хугацаагаар, дараалсан өдрийн тоо, «Алгебр мастер» гэх мэт тэмдэг. Ангийн оролцооны самбар (оноо биш, хийсэн асуултын тоо).
- **Сүлжээ тасарсан ч алдахгүй:** хариултууд төхөөрөмжид хадгалагдаж, холбогдмогц автоматаар илгээгдэнэ.
- **Үгсийн сан:** SAT-ийн 100+ түгээмэл үг карт болон тест хэлбэрээр.

**Багш нар**
- **Анги, даалгавар:** хугацаа, хаагдах огноо, түвшин, асуултын эх үүсвэр сонгоно.
- **Шууд асуулт (Kahoot маягийн):** асуултыг том дэлгэцэд гаргаж, сурагчид утсаараа хариулна. Хариултын тархалт, тэргүүлэгчид шууд харагдана.
- **Давтагддаг даалгавар:** «Даваа гараг бүр 8:00-д 8 асуулт» гэх мэт автоматаар үүснэ.
- **Ангийн шинжилгээ:** хамгийн сул сэдэв, 60%-иас доош сурагчид, хамгийн их алддаг асуултууд.
- **Сул сурагчдад нэмэлт даалгавар:** нэг товчоор, зөвхөн тэдэнд зориулж, хамгийн сул сэдвээр нь.
- **Сурагчийн дэлгэрэнгүй:** явцын график, сэдэв бүрийн дүн, тэмдэг. PIN мартсан сурагчийн PIN-ийг шинэчилнэ.
- **Асуултын сан:** суурь санд 40 асуулт. Багш өөрийн асуултаа түвшинтэй нь нэмнэ.
- **Хамтран ажиллах багш:** ангид өөр багшийг имэйлээр нэмнэ.
- **Нууц үг сэргээх:** бүртгүүлэхэд гарах сэргээх кодоор нууц үгээ шинэчилнэ. «Бүртгэл» цэснээс нууц үг солих, шинэ код авах.
- **CSV татах, том дэлгэцээр үзүүлэх.**

## Бүтэц

```
server.js            Express сервер, бүх API
db.js                PostgreSQL холболт (DATABASE_URL байхгүй бол туршилтын санах ой)
data/questions.js    Асуултын сан (монгол/англи). Шинэ асуулт энд нэмнэ.
public/              Вэб хуудсууд
  index.html         Нүүр: дасгал, үгс, томьёо, холбоос
  student.html       Сурагчийн хуудас
  teacher.html       Багшийн хуудас
  css/style.css      Загвар
  js/                common.js, practice.js, student.js, teacher.js
render.yaml          Render-ийн тохиргоо
```

## Компьютер дээрээ ажиллуулах

[Node.js](https://nodejs.org) 18 буюу түүнээс дээш хувилбар хэрэгтэй.

```bash
npm install
npm start
```

Хөтөч дээр http://localhost:3000 нээнэ. `DATABASE_URL` тохируулаагүй үед өгөгдөл түр санах ойд хадгалагдаж, сервер унтрахад устна.

## 1-р алхам: GitHub-д байршуулах

## 2-р алхам: Мэдээллийн сан бэлдэх

Сурагчдын дүн байнга хадгалагдахын тулд PostgreSQL заавал хэрэгтэй. Render-ийн үнэгүй сервер унтах, дахин эхлэх бүрт файлууд устдаг.

**Сонголт A — Neon (үнэгүй, хугацаагүй):**
1. [neon.tech](https://neon.tech) дээр бүртгүүлж, шинэ project үүсгэнэ.
2. **Connection string**-ийг хуулна (`postgresql://...` гэж эхэлнэ).

**Сонголт B — Render Postgres:** Render-ийн үнэгүй мэдээллийн сан **30 хоногийн дараа хүчингүй** болдог тул удаан ашиглах бол төлбөртэй багц сонгоно. Үүсгэсний дараа **Internal Database URL**-ийг хуулна.

## 3-р алхам: Render дээр байршуулах

1. [render.com](https://render.com) дээр GitHub бүртгэлээрээ нэвтэрнэ.
2. **New → Blueprint** сонгоод `onoo1600` repository-г холбоно. Render `render.yaml`-ийг уншиж, вэб үйлчилгээг автоматаар үүсгэнэ.
3. Хувьсагчид утга оруулна:
   - `DATABASE_URL` — 2-р алхамд хуулсан хаяг
   - `TEACHER_INVITE_CODE` — багшаар бүртгүүлэх нууц код (жишээ: `SCHOOL2026`). Хоосон орхивол хэн ч багшаар бүртгүүлж чадна.
   - `APP_TZ` (заавал биш) — цагийн бүс, анхны утга `Asia/Ulaanbaatar`. Давтагддаг даалгавар, streak үүгээр тооцогдоно.
4. **Apply** дарна. Хэдэн минутын дараа `https://onoo1600.onrender.com` гэх мэт хаяг гарна.

> Blueprint ашиглахгүй бол: **New → Web Service**, Build command `npm install`, Start command `npm start`, дээрх 2 хувьсагчийг **Environment** хэсэгт нэмнэ.

Давтагддаг даалгавар сервер унтаж байх үед ч алдагдахгүй: сурагч эсвэл багш сайтад ороход хоцорсон даалгавар үүснэ.

Үнэгүй сервер 15 минут ашиглагдахгүй бол унтаж, дараагийн нээлтэд 1 минут орчим ачаална. Хичээлийн өмнө сайтаа нэг нээгээд сэрээж болно.

## Ашиглах заавар

**Багш:**
1. `/teacher` хуудсанд урилгын кодоор бүртгүүлнэ. Гарч ирэх **сэргээх кодыг заавал хадгална** — нууц үгээ мартвал зөвхөн үүгээр сэргээнэ.
2. Анги үүсгэхэд 6 тэмдэгттэй **ангийн код** гарна. Үүнийг сурагчдад өгнө.
3. **Даалгавар өгөх:** хичээл, сэдэв, асуултын тоо, хугацаа (минут), хаагдах огноог сонгоно. Хугацааг асуултын тоогоор бодит SAT-ийн хурдаар автоматаар санал болгоно.
4. **Дүн** товчоор сурагч бүрийн төлөв, оноо, сул сэдэв, асуулт тус бүрийн гүйцэтгэлийг харна. 15 секунд тутам шинэчлэгдэнэ.

**Сурагч:**
1. `/student` хуудсанд ангийн код, нэр, 4 оронтой PIN оруулна. Өөр төхөөрөмжөөс ижил нэр, PIN-ээр нэвтэрнэ.
2. Даалгаврыг **Эхлэх** дармагц цаг явна. Хуудсаа хаасан ч цаг зогсохгүй, буцаж ороход хариултууд хадгалагдсан байна.
3. Илгээсний дараа оноо, сэдэв бүрийн дүн, асуулт бүрийн тайлбарыг харна.

## Шинэ асуулт нэмэх

**Хялбар арга:** багшийн хуудасны «Миний асуултын сан» хэсгээс «Асуулт нэмэх». Эдгээр асуулт мэдээллийн санд хадгалагдаж, зөвхөн тухайн багшид харагдана.

**Бүх багшид нээлттэй суурь санд нэмэх бол** `data/questions.js` файлд дараах бүтцээр нэмээд GitHub руу push хийхэд Render автоматаар шинэчилнэ:

```js
{ id: "M-alg-4", subject: "M", domain: "alg",
  q_en: "English question", q_mn: "Монгол асуулт",
  passage_en: "(заавал биш) эх текст",
  options_en: ["A", "B", "C", "D"], options_mn: ["(заавал биш)", "", "", ""],
  answer: 0,                       // 0=A, 1=B, 2=C, 3=D
  e_en: "Explanation", e_mn: "Тайлбар" }
```

`id` давхардахгүй байх ёстой. Даалгаварт орсон асуултын `id`-г өөрчилж болохгүй.

## Хамгаалалт

- Нууц үг, PIN нь bcrypt-ээр шифрлэгдэнэ.
- Даалгаврын үед зөв хариулт хөтөчид илгээгдэхгүй, оноог сервер тооцно.
- Хугацаа хэтэрсэн илгээлт «Хоцорч илгээсэн» гэж тэмдэглэгдэнэ (сүлжээний сааталд 30 секунд уян хатан).
